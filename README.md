# ugurcanhatirli.github.io

Personal website of Uğur Can Hatırlı.

A selection of writing and notes on politics, political thought, philosophy, and society, with occasional excursions into language, culture, and technology.

Built with Astro and hosted on GitHub Pages.

## Development

Install dependencies:

```sh
npm ci
```

Start the local development server:

```sh
npm run dev
```

Create a production build:

```sh
npm run build
```
